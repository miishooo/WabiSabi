# Wabisabi | موقع سياحي لليابان 🗾

موقع سياحي تفاعلي يعرض أبرز الوجهات السياحية في اليابان، مع أدوات تساعد المستخدم
على التخطيط لرحلته، مثل عرض الوقت ودرجة الحرارة، وخطة سياحية جاهزة، وفلاتر للجهات
المتاحة (مطاعم، فنادق، مقاهي، وجهات سياحية)، ونظام مفضلات.

** تم انشاء هذاء الموقع تحت مشروع مقرر تطوير الويب 1 **

---

## مميزات موقعنا

### الصفحة الرئيسية
- تعريف بالموقع ورسالته
- عرض ثلاث من أهم الوجهات السياحية في اليابان
- عرض الوقت الحالي في **اليابان** و**السعودية** بشكل مباشر (JavaScript)
- عرض درجة الحرارة الحالية **اليابان** و**السعودية** بشكل مباشر (JavaScript)

### صفحة "من نحن"
- تعريف مفصّل بنا كجهه سياحيه والمعنى في اسمنا مع مميزاتنا
- عرض مثال لخطة سياحية جاهزة
- ربط أماكن الخطة بخرائط **Google Maps**

### صفحة الجهات
- عرض جميع الجهات المتاحة
- فلترة الجهات حسب النوع: **مطاعم، فنادق، مقاهي، وجهات سياحية**
- زر **المفضلات**: يسمح للمستخدم بحفظ الجهة، وتنتقل مباشرة إلى صفحة المفضلات

### صفحة التواصل
- نموذج تواصل بسيط
- نظام تقييم للموقع
